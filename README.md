Sparta Academy API – Setup and Run Guide

Requirements : Java 21, Maven, Git, An IDE like IntelliJ


Instructions

1. Clone the repository:
git clone https://github.com/NikitaKumai24/sparta-academy-api.git

2. Open the project in your IDE.

3. Run the application from IDE - Run the SpartaApiApplication main class.
   
4. Accessing the Application (Swagger API Documentation) - Open this link in your browser once the app is running:
   http://localhost:8091/swagger-ui.html

5. From here you can: See all available endpoints, Send GET, POST, PUT, DELETE requests, View request and response formats
